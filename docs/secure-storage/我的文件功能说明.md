# 基于加密技术的文件共享系统 - 功能实现说明

本文档描述需求中**已实现**功能的实现方式及代码位置。

---

## 一、用户模块

### 1.1 注册与登录（MD5 加密存储）

**实现方式：** 密码使用 Hutool 的 `DigestUtil.md5Hex()` 加密后存储，登录时对明文密码做 MD5 后与数据库密文进行字符串比对。

| 功能     | 代码位置 |
|----------|----------|
| 注册加密 | `ruoyi-admin/.../SysRegisterService.java`：`DigestUtil.md5Hex(password)` |
| 登录校验 | `ruoyi-admin/.../impl/PasswordAuthStrategy.java`：`DigestUtil.md5Hex(password).equals(user.getPassword())` |
| 改密码   | `ruoyi-modules/ruoyi-system/.../SysProfileController.java`：旧密码校验、新密码加密后调用 `resetUserPwd` |

---

### 1.2 文件管理（上传自动加密、下载自动解密、删除）

**实现方式：** 上传时使用 AES 流式加密后写入 OSS，下载时从 OSS 读取加密数据并流式解密输出。

| 功能     | 实现说明 | 代码位置 |
|----------|----------|----------|
| 上传加密 | 接收文件后通过 `AesStreamUtil.encrypt()` 加密，再上传至 MinIO/OSS | `ruoyi-secure/.../BizUserFileServiceImpl.java`（`uploadFile` 方法） |
| 下载解密 | 从 OSS 获取加密文件流，通过 `AesStreamUtil.decrypt()` 流式解密输出 | `ruoyi-secure/.../BizUserFileServiceImpl.java`（`downloadFile`、`downloadFileByShare`） |
| 删除     | 删除 `biz_user_file` 记录及 OSS 中的加密文件 | `BizUserFileController.java`：`DELETE /secure/file/{fileIds}` |

**AES 工具类：** `ruoyi-secure/.../util/AesStreamUtil.java`（AES/CBC/PKCS5Padding）

---

### 1.3 安全共享（加密分享链接、有效期、访问密码）

**实现方式：** 创建分享时生成短链接，可设置有效期（永久/7天/1天）和提取码；访问者通过分享链接 + 提取码（若需）校验后获取下载凭证，免登录下载。

| 功能       | 实现说明 | 代码位置 |
|------------|----------|----------|
| 创建分享   | `fileId`、`expireDays`、`needCode`，生成短链接及可选提取码 | `BizFileShareServiceImpl.java`：`createShare` |
| 提取校验   | 校验链接有效性、过期时间、提取码 | `BizFileShareServiceImpl.java`：`extractShare` |
| 免登录下载 | 校验 Redis 中的 token 后流式解密输出 | `BizFileShareServiceImpl.java`：`downloadByShare` |

**接口：**
- `POST /secure/share/create`：创建分享
- `POST /secure/share/extract`：校验并提取（免登录）
- `GET /secure/share/download`：免登录下载

**前端：** `secure-storage-ui/src/views/secure/userFile/UserFile.vue`（分享弹窗）、`share/Share.vue`（分享提取页）

---

### 1.4 权限管理

> 需求中的「为不同用户或群组设置不同的访问权限（如仅预览、可下载）」未实现，当前分享链接仅支持「可下载」一种权限。

---

### 1.5 个人中心

**实现方式：** 基于若依个人中心，支持查看/修改个人信息、修改登录密码；文件管理在「我的文件」页面完成。

| 功能           | 实现说明 | 代码位置 |
|----------------|----------|----------|
| 个人信息       | 查看、修改昵称、手机、邮箱等 | `ruoyi-system/.../SysProfileController.java`、前端 `views/system/user/profile/index.vue` |
| 修改密码       | 校验旧密码后调用 `resetUserPwd`，新密码 MD5 加密 | `SysProfileController.java`：`updatePwd` |
| 管理自己的文件 | 在「我的文件」页面进行上传、下载、分享、删除 | `views/secure/userFile/UserFile.vue` |

## 二、管理员模块

### 2.1 用户管理

**实现方式：** 使用若依系统自带的用户管理，支持审核、添加、修改、禁用、删除用户。

| 功能 | 代码位置 |
|------|----------|
| 用户 CRUD | `ruoyi-modules/ruoyi-system/.../SysUserController.java` |
| 用户服务 | `ruoyi-modules/ruoyi-system/.../impl/SysUserServiceImpl.java` |
| 前端页面 | `secure-storage-ui/src/views/system/user/index.vue` |

**菜单路径：** 系统管理 → 用户管理

---

### 2.2 文件审计

**实现方式：** 记录文件上传、下载、分享、删除操作，支持按操作类型、操作人、时间筛选。普通用户仅能查看本人日志，超级管理员可查看全部。

| 功能     | 代码位置 |
|----------|----------|
| 后端接口 | `ruoyi-secure/.../BizFileOperateLogController.java`：`GET /secure/fileLog/list` |
| 服务层   | `ruoyi-secure/.../impl/BizFileOperateLogServiceImpl.java` |
| 前端页面 | `secure-storage-ui/src/views/secure/fileLog/FileLog.vue` |

**菜单路径：** 安全存储 → 文件日志

---

### 2.3 系统监控

**实现方式：** 使用若依自带的系统监控模块（在线用户、操作日志、登录日志等），未单独实现「异常访问或潜在安全威胁告警」功能。

**菜单路径：** 系统监控 → 在线用户 / 操作日志 / 登录日志 等

---

### 2.4 管理员个人中心

**实现方式：** 与普通用户共用同一个人中心，管理员可修改自己的账户信息及密码。

**代码位置：** 同 1.5 个人中心。

---
